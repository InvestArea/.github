## 🎯 Missiya və Hədəf

**InvestArea** — işğaldan azad edilmiş Qarabağ və Şərqi Zəngəzur iqtisadi rayonlarında kənd təsərrüfatı təyinatlı torpaq sahələrinə investisiya cəlbini sürətləndirən, açıq müsabiqə müraciətlərini tam rəqəmsallaşdıran və dövlət aqrar informasiya sistemlərinə (EKTİS, LADM, AVİS) inteqrasiya olunan vahid platformadır.

Platforma torpaqların bonitet ballarını, suvarma şəbəkəsini, ANAMA minatəmizləmə statusunu və relyef amillərini vahid Geoinformasiya Sistemi (QGIS) xəritəsində birləşdirir, investorlar üçün şəffaf müsabiqə mühiti yaradır.

## 🚀 Əsas Funksional İmkanlar

1. **🗺️ İnteraktiv CİS Aqrar Xəritəsi:** Ağdam, Füzuli, Cəbrayıl, Zəngilan, Laçın, Kəlbəcər və digər rayonlar üzrə vektor poliqonlar, suvarma kanalları, yaşayış məntəqələri və dinamik torpaq təftişi.
2. **📊 Müsabiqə Kataloqu və Müqayisə:** Aktiv lotların (əkinçilik, bağçılıq, heyvandarlıq, istixana) parametr-parametr yan-yana (*side-by-side*) müqayisəsi.
3. **📝 5 Addımlı Elektron Müraciət:** VÖEN/FİN avtomatlaşdırılmış yoxlanışı, biznes plan göstəriciləri, sənəd əlavəsi və unikal izləmə kodu (`INV-2026-AGD-XXXX`).
4. **🤖 Qarabağ Aqro-AI və ROI Analizi:** 5 illik gəlirlilik proqnozu, aqronomik tövsiyələr və sənədlərin 100 ballıq intellektual skorinqi.
5. **🏛️ 9 Dövlət Qurumunun Canlı Kollegial Səsverməsi:** KTN, İN, ƏMDX, ETSN, ADSEA, AXA, AKİA, PXN və EKTİS üzrə şəffaf qiymətləndirmə mexanizmi.
6. **🛰️ Sentinel-2 Peyk NDVI Monitorinqi:** Vegetasiya sağlamlığı və sahələrin real vaxt rejimində kosmik təsvirlərlə monitorinqi.

## 📐 Standartlar və Texnoloji Arxitektura

- **Beynəlxalq Kadastr Standartları:** ISO 19152 LADM (*Land Administration Domain Model*), FAO/UN-Habitat SOLA (*Solutions for Open Land Administration*).
- **Geoməkan / GIS:** QGIS, Leaflet.js, GeoJSON, PostGIS.
- **Backend & API:** Java 21 / Spring Boot 3, Node.js Gateway, OpenAPI / Swagger.
- **Verilənlər Bazası:** PostgreSQL 16 + PostGIS, H2 In-Memory.
- **Təhlükəsizlik & İdentifikasiya:** SİMA Biometrik İmza, ASAN İmza, myGov, OAuth 2.0.
